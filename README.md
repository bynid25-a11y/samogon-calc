# 🧪 АлкоКалькулятор Pro (AlcoCalc Pro)

> Физически точный веб-калькулятор винокура и дистиллятора с учетом контракции Менделеева, расчета голов/тела и гидромодуля браги.

🔗 **Онлайн**: [https://bynid25-a11y.github.io/samogon-calc/](https://bynid25-a11y.github.io/samogon-calc/)

---

## 🚀 Возможности
- **Точное разбавление водой**: учет молекулярного сжатия раствора (контракции) по таблицам Менделеева/OIML при 20°C. Расчет в миллилитрах и граммах для кухонных весов.
- **Отбор фракций (вторая перегонка)**: расчет абсолютного спирта (АС), голов (7–15%), питьевого тела (~88% в струе) и хвостов с прогнозом выхода готового 40% напитка в бутылках по 0.5 л.
- **Брага и гидромодуль**: расчет объема сусла, плотности в °Brix, спиртуозности браги и потенциального выхода дистиллята из сахара.
- **Коррекция ареометра АСП-3**: температурная поправка плотности спиртомера при замерах теплого или холодного погона.
- **PWA & Offline**: работает на смартфоне и ПК без интернета.
- **URL State**: легкий шеринг пропорций одной ссылкой.
